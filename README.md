# 返ってきた数学のテスト、「どこから直す？」で止まっていませんか

テストが返ってくると、まず〇と×の数を見て、それから直しに入る——多くのご家庭がそうだと思います。

でも、実際に机に向かわせると、だいたいここで止まります。

「どこから直せばいいの？」  
「この問題、どの単元だっけ？」  
「直しノート書いたのに、次のテストでまた同じところ落とす」

直しそのものが悪いわけではありません。問題は、直しが「その場の作業」で終わってしまい、**お子さんがどこでつまずいているのか**が見えづらいことです。親も「ちゃんと直させた」つもりなのに、次の単元テストで同じパターンが出ると、お互いに疲れてしまいます。

## 丸付けのあとに、地図がほしい

ドリルや宿題の丸付けも同じです。マルをつけて、直しをさせて、終わり。親も子も、その日のノルマは達成したつもりになります。

でもテスト前の夜になると、また同じ悩みが出てきます。

「結局、何から手をつければいいの？」

解説プリントやワークも役に立ちます。ただ、うちの子に今いちばん必要なのは、新しい問題をもっと増やすことより、**これまで間違えたところが地図のように見えること**かもしれません。地図があれば、「今夜はここだけ」と区切れます。区切れると、机に向かうハードルが下がります。

## つまずきマップという考え方

[つまずきマップ](https://tsumazuki.domo-ai.com/)は、小1〜高3の算数・数学向けに、その「地図」をつくるツールです。

流れはシンプルです。

1. 宿題・ドリル・返ってきたテストを撮る  
2. AIが問題ごとに単元を見分けて、○✕を記録する  
3. 毎日の解き直しと、テスト前の「今夜の作戦」につなげる

「写真を撮る」ところから始まるので、直しノートをきれいに書かせる前に、まず記録が残ります。親が単元名を全部覚えていなくても、問題ごとに整理されます。

ワークや解説を置き換えるものではなく、**撮ったものからつまずきを見える化し、今夜やることが決まる**——そういう立ち位置です。解説は学校や市販のものに任せつつ、「どこが弱いか」「今夜何をするか」だけを家で持つ、という分け方もできます。

## テスト前の夜に欲しいもの

テスト前日にいちばん困るのは、量ではなく順番です。

全部やり直す時間はない。でも、弱いところは潰したい。そのときに、「今夜の作戦」があると、机に向かうハードルが下がります。

作戦の材料になるのは、その日急に書いたメモではなく、これまで撮っておいた宿題・ドリル・テストの○✕です。だから、平常時に少しずつ撮っておくほど、テスト前が楽になります。週末に返ってきたテストを一枚撮っておくだけでも、翌週の作戦の材料になります。
